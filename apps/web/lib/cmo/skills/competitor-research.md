# Competitor research

## Steps
1. Take the competitors from the competitors document; find their accounts on X (and video platforms if they use them).
2. For each, find the outliers (see outlier-research) instead of reading their feed top to bottom.
3. Map what each one does: content pillars, formats, hooks, cadence, calls to action.
4. Find the gaps: pains the customers raise that no competitor talks about; formats nobody uses well; angles where the founder's product is genuinely different.
5. Turn gaps into 3-5 concrete content tests for the founder, each with the URL that inspired it.

## Rules
- Compare by lift against each account's own baseline, never by follower count.
- Say "appears to" for inferred strategy. Never invent spend, targeting or results.
- Note what NOT to copy: tactics that only work for a big audience or that clash with the brand voice.
